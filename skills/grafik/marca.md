# Manual de marca

Llena esta tabla y grafik usará estos colores en todos los videos del proyecto.

**Todos los valores en hexadecimal (`#rrggbb`).** Si escribes "azul corporativo"
o pegas una muestra sin el código, el resultado va a ser un color parecido y no
el tuyo. En un video eso se nota.

Si un rol no aplica, borra la fila: se usa el valor por defecto de Wiracocha.

| Variable | Para qué | Hex |
|---|---|---|
| `--acento` | títulos, enlaces, barras | `#d4af37` |
| `--acento-2` | diagramas y énfasis | `#f27d42` |
| `--acento-3` | escena de cierre | `#a9442b` |
| `--fondo` | fondo del lienzo | `#2f2e2b` |
| `--superficie` | placa de contraste sobre el fondo | `#2e1e1a` |
| `--texto` | texto corrido | `#d9d9d9` |
| `--ok` | correcto, confirmado | `#3ecf6a` |

## Tipografía

Opcional. Si usas una fuente propia, deja el `.woff2` en el proyecto y anota la
ruta relativa. Sin esto se usa la pila del sistema.

```
Nombre:
Archivo:
```
